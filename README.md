# Personal Portfolio

A modern responsive portoflio website built using React.js and Bootstrap to showcase my projects, skills, resume and contact information.

## Features
- Responsive desgin for desktops and mobiles
- Project showcase with project details
- Resume preview and download
- contact info
- certificates page
- smooth navigation (used react-router-dom)
